# credit-risk
A project consisting of exploration of data and modelling credit risk

# About Data
Data is not included here cause of the restrictions about the datasets used in the project.
However you can download them following the next steps :
1. Create or use your [Kaggle] account: (https://www.kaggle.com)
2. Accept the rules of the competition: https://www.kaggle.com/c/home-credit-default-risk/data
3. Download the .zip and put it on the `data/` folder
